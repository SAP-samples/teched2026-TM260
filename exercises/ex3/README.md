### Exercise 3.1 Use GitHub Copilot and ADT MCP tools to create CDS View for the data of the Clean Core Planning ABAP program 

By following these steps you will use GitHub Copilot and ADT MCP tools to create the CDS view for reading the data of the SAP GUI ABAP program for **Clean Core Planning** .

1. Ask the GitHub Copilot in chat to generate the CDS view by providing the following prompt: **Create a CDS view based on the view I_CUSTABAPOBJDIRECTORYENTRY and join the data from table **`ZTM260_CCP_###`**. Use the package **`ZTM260_EXERCISES_###`**. Use the naming convention ZTM260 at the beginning and the number _### at the end**. The GitHub Copilot will use the ADT MCP tools and create and activate the CDS view. 

   <br>![](/exercises/ex3/images/tm260_ex3_1_generate_cds_view.png)
   
2. Go to your newly created CDS view **`ZTM260_CCP_JOIN_###`** in your package **`ZTM260_EXERCISES_###`** and use **F8** (or the context menu *Open With > Data Preview*) to display the data. Use the table column *Add Filter* to add *DevelopmentPackage* filter and enter the package **ZTM260_CLEAN_CORE_SAMPLES**. Verify that the same data are also displayed as in the SAP GUI ABAP program.
 
   <br>![](/exercises/ex3/images/tm260_ex3_2_preview_cds_view.png)

### Exercise 3.2 Use GitHub Copilot and ADT MCP tools to generate a modern SAP Fiori- and RAP-based Clean Core Planning application on top of the CDS view

By following these steps you will use the GitHub Copilot and ADT MCP tools to generate a new modern SAP Fiori and RAP-based application.

1. Go to your GitHub Copilot chat and provide the following prompt: **Based on the CDS view **`ZTM260_CCP_JOIN_###`** create a simple RAP application in the package **`ZTM260_EXERCISES_###`** which displays the data of the view in a Master details Pattern UI. Use the naming convention of the view: all artifacts begin with ZTM260_ and end with **`_###`**.**. The GitHub Copilot will generate the SAP Fiori and RAP-based application using the ADT MCP tools:

   <br>![](/exercises/ex3/images/tm260_ex3_3_gen_rap_app.png)
   
2.	Check in the *Project Explorer* which objects were generated by the GitHub Copilot in your package **`ZTM260_EXERCISES_###`**:
   
   <br>![](/exercises/ex3/images/tm260_ex3_4_view_gen_objects.png)
   
3.	In the *Project Explorer* double click on the Service Binding to display it in the editor, use the shortcut **Ctrl + Alt + R** and select the ADT IDE action to *Publish locally* and click on the *Run* button to publish the service.

   <br>![](/exercises/ex3/images/tm260_ex3_5_publish.png)
   
4.	Now refresh the display of the Service Binding in the editor *File > Refresh (F5)* and click on the *Preview* button.

    <br>![](/exercises/ex3/images/tm260_ex3_6_preview.png)
   
5. You will see the preview of your new SAP Fiori RAP-based application. Click on the *Go* button and you will see that the same data are also displayed in the SAP Fiori app as in the SAP GUI ABAP program for **Clean Core Planning**. You have successfully generated the SAP Fiori and RAP-based application for **Clean Core Planning** based on the data of the SAP GUI ABAP program.

    <br>![](/exercises/ex3/images/tm260_ex3_7_show_fiori_app.png)

6.	**Optional:** Use further prompts in the GitHub Copilot chat to enhance your SAP Fiori RAP-based application.


### Summary
You have modernized the existing SAP GUI-based ABAP program for **Clean Core Planning** by creating a new modern SAP Fiori and RAP-based application using GitHub Copilot and ADT MCP tools on top of the persistency of the ABAP program.
