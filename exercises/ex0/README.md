## Introduction

1. The screenshots for the exercises 1-3 have been prepared in the SAP Business AI Platform, ABAP environment system **`S01`** and in the ABAP backend system **`HE4`** using the ABAP user **`TM260-00`** with the group ID **`00`**.
2. The explanation in the exercises will remind you to use your assigned location and group number (indicated by **`###`**), e.g. ABAP program **`ZTM260_MATERIAL_READ_###`**. 
3. You will work in the ABAP development tools for Eclipse in the standard ABAP package **`ZTM260_EXERCISES_###`**.
4. The solution package is provided as **`ZTM260_EXERCISES_SOL`**.
5. Please note, that your AI content generated during execution of exercises can vary from the content provided on the screenshots.
6. Please also note that dialogs and views of ABAP system and ABAP development tools for Eclipse, as well as SAP Fiori UIs, may change in future releases.
